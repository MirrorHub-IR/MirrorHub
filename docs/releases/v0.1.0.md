# MirrorHub v0.1.0 — Initial Public Preview

> **Release status:** These are the proposed notes for the first public preview. They become an actual GitHub Release only after maintainers run the Draft Release workflow, review the generated draft, and publish it.

## English

### Highlights

- Self-hosted PHP and MySQL/MariaDB application for discovering software mirrors.
- Public mirror catalogue with category/provider pages, search, filters, mirror details, and copyable repository setup templates.
- Scheduled HTTP/HTTPS monitoring for active provider mirrors, including response history, daily uptime, incidents, and a public status page.
- Optional repository-metadata freshness checks for Debian/Ubuntu, Alpine, Arch Linux, RPM, and custom metadata paths.
- Public REST-style API v1 with pagination, filtering, OpenAPI 3.1 documentation, and shell examples.
- Moderated mirror contributions with validation, anti-bot handling, and per-IP rate limiting.
- Integrated Markdown guide CMS with category association, SEO metadata, and live stored-health blocks.
- Browser-based setup wizard, administrator tools, configurable monitoring, and JSON/ZIP backup and restore.
- Responsive Persian-first interface with local Vazirmatn font assets.

### Installation

Use the browser installer at /setup.php on a fresh deployment. Read [docs/installation.md](../installation.md) for prerequisites, database setup, configuration, Cron, and deployment security. The Persian guide is available at [docs/installation.fa.md](../installation.fa.md).

### Validation included in the repository

- PHP syntax checks.
- PHP security/regression smoke tests.
- JavaScript syntax checks.
- Semgrep static-analysis workflow for PHP.

These checks do not include a live MySQL/MariaDB integration environment or browser-based end-to-end coverage.

### Known limitations

- Repository metadata checks do not perform full GPG signature verification and do not verify every package hash.
- HTTP availability does not prove repository completeness or package authenticity.
- Browser Ping is an HTTP timing measurement, not ICMP.
- Production deployment, database migrations, scheduled monitoring, backup restoration, and administrator workflows should be validated in staging.
- The project is an initial pre-1.0 public preview and may change as operator feedback is collected.

## فارسی

### معرفی نسخه

این نسخه، پیش‌نمایش عمومی اولیهٔ MirrorHub است؛ یک برنامهٔ خودمیزبان PHP و MySQL/MariaDB برای کشف میرورهای نرم‌افزاری، مدیریت ارائه‌دهندگان و پایش وضعیت آن‌ها.

### مهم‌ترین قابلیت‌ها

- فهرست عمومی میرورها با جست‌وجو، فیلتر، دسته‌بندی، صفحهٔ ارائه‌دهنده و جزئیات میرور.
- پایش دوره‌ای HTTP/HTTPS، تاریخچهٔ پاسخ، آپتایم روزانه، رخدادهای قطعی و صفحهٔ وضعیت.
- بررسی اختیاری تازگی Metadata برای Debian/Ubuntu، Alpine، Arch، RPM و مسیر سفارشی.
- API عمومی نسخهٔ ۱ به همراه صفحه‌بندی، فیلترها، OpenAPI 3.1 و نمونه‌های Shell.
- ثبت پیشنهاد میرور با اعتبارسنجی، ضدربات، محدودیت نرخ و تأیید مدیر پیش از انتشار.
- CMS راهنماهای Markdown با اتصال به دسته، اطلاعات SEO و بلوک وضعیت ذخیره‌شدهٔ میرورها.
- نصب‌کنندهٔ مرورگری، پنل مدیریت، تنظیمات پایش و بکاپ/بازیابی JSON و ZIP.
- رابط واکنش‌گرا با پشتیبانی از فارسی و فونت محلی Vazirmatn.

### نصب

در نصب تازه مسیر /setup.php را از مرورگر باز کنید. پیش‌نیازها، ساخت دیتابیس، تنظیمات، Cron و نکات امنیتی در [راهنمای نصب انگلیسی](../installation.md) و [راهنمای نصب فارسی](../installation.fa.md) آمده‌اند.

### بررسی‌های موجود

- بررسی Syntax فایل‌های PHP.
- تست‌های دود امنیتی و رگرسیون PHP.
- بررسی Syntax فایل‌های JavaScript.
- گردش‌کار تحلیل ایستای CodeQL برای PHP.

این بررسی‌ها شامل دیتابیس واقعی MySQL/MariaDB یا تست End-to-End مرورگر نیستند.

### محدودیت‌های شناخته‌شده

- بررسی Metadata شامل اعتبارسنجی کامل امضای GPG یا همهٔ Hash بسته‌ها نیست.
- پاسخ HTTP، کامل بودن مخزن یا اصالت بسته‌ها را اثبات نمی‌کند.
- Ping مرورگر فقط زمان یک درخواست HTTP است و ICMP نیست.
- نصب تولیدی، Migration، Cron، بازیابی بکاپ و گردش‌کارهای مدیر باید در محیط Staging آزمایش شوند.
- پروژه در مرحلهٔ پیش‌نمایش اولیه و پیش از نسخهٔ ۱.۰ است و ممکن است بر اساس بازخورد اپراتورها تغییر کند.

### مجوز

کد برنامه تحت GPL-3.0-only است. فونت Vazirmatn مجوز مستقل SIL Open Font License 1.1 دارد که متن آن در assets/fonts/OFL.txt قرار گرفته است.
