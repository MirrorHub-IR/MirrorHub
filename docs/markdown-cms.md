# راهنمای CMS مارک‌داون MirrorHub

این CMS بخشی از خود برنامهٔ PHP/MySQL است و دیتابیس جداگانه‌ای ایجاد نمی‌کند. مقاله‌ها در جدول `cms_articles` ذخیره می‌شوند و به دسته‌بندی‌های نرم‌افزار فعلی وصل می‌شوند.

## امکانات نسخهٔ نخست
- مدیریت مقاله‌ها از `/admin/pages.php`؛ پیش‌نویس، انتشار، ویرایش و حذف.
- ذخیرهٔ متن با Markdown و رندر امن با فرار دادن HTML خام.
- خلاصه، عنوان SEO، توضیحات SEO و URL استاندارد برای هر مقاله.
- صفحات عمومی در `/guides/` و `/guides/{slug}`.
- نقشهٔ سایت XML در `/sitemap.xml`.
- کارت سلامت میرورها با استفاده از وضعیت ثبت‌شده در سامانهٔ مانیتورینگ.
- پس از انتخاب دستهٔ نرم‌افزار و انتشار مقاله، لینک آن به‌صورت خودکار در صفحهٔ همان دسته (مثلاً Ubuntu) نمایش داده می‌شود؛ چند مقاله می‌توانند به یک دسته وصل باشند.

## کارت سلامت زنده
در خط جداگانهٔ مقاله بنویسید:

```text
:::health alpine
```

به‌جای `alpine`، نامک دستهٔ نرم‌افزار موجود را قرار دهید. کارت هنگام نمایش مقاله وضعیت ذخیره‌شدهٔ میرورهای فعال همان دسته را می‌خواند. این داده‌ها در متن مقاله کپی نمی‌شوند.

## آدرس‌های تمیز
فایل `.htaccess` مسیرهای `/guides/` و `/guides/{slug}` را به `docs.php` و `/sitemap.xml` را به `sitemap.php` هدایت می‌کند. این مسیر عمداً از `/docs/` استفاده نمی‌کند، چون پوشهٔ docs در مخزن برای مستندات توسعه‌دهندگان وجود دارد.

## نکتهٔ بکاپ
مقاله‌ها در همان دیتابیس MirrorHub هستند؛ بنابراین بکاپ SQL کامل دیتابیس آن‌ها را نیز شامل می‌شود. فایل‌های Markdown جداگانه لازم نیستند.
